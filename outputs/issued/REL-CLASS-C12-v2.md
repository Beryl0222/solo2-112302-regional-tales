## 二、馆方考订与教学说明（馆方解释，可与原话对照讲授）

### 1. 术语“版”的修订解释（v2）
在绝版木刻中，‘版’首先指套色版次，即同一母版边刻边印、逐版递减过程中的一个刻印状态或色层；它不是另一块板，不是一个独立版本，也不是一张独立作品。

- **版次/刻印状态**：绝版木刻同一母版逐版递减中的一个套色阶段，不是另一块板、另一作品。
- **张数**：“一张”指印出的纸张；C12 只有作品编号、没有张号，张数不可考。
- **版本（出版物意义）**：本批口述无证据采用。
- 教学提醒：修订术语后不能只做全文替换；q2 全句没有“版”字，但因“刻毁/红土”链接到母版与版次事件，仍须重判。

### 2. 人物与创作归属
- 作品卡 w1 与 p2：**周敏创作、署个人名；贺昆为导师/版画教师**。
- 师生共展与技艺沿袭把贺昆、周敏双方连到同一条绝版木刻技艺脉络，但**不把 C12 归为贺昆所有**。
- l1 提出“教师示范后共同制作”，这是课程改写稿中的**对立主张（claim:l1-joint）**，在没有示范记录或共同制作证据前，不覆盖作品卡；可作为课堂史料对读问题。

### 3. 事件不能折叠
创作、刻版、套印、收藏、展览是不同事件；母版刻毁是刻版的终点，也单独登记。“最后版次状态”和此前各刻印状态属于同一块母版的不同阶段，不能折叠成“一张作品”的先后版本，也不能把红土色层擅自排到毁版之前或之后。收藏事件在现有语料中是材料缺口，不要替学生补造收藏故事。

### 4. 课堂讨论：这个“它”指什么？
展示 h0 原句与两个候选（母版 / 上一张印纸），让学生分别检验搭配与时序：
若“它”是母版，则“母版便毁了”之后无法再刻；若“它”是印纸，则与“刻”和“刀痕”不合。结论应是：**句子本身需要拆分改写，候选可以并存，不能为了通顺替古人/口述者定指。**
